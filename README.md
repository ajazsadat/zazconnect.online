# ZazConnect (zazconnect.online)

Next.js site for **ZazConnect** — independent internet/TV comparison and referral platform operated by **Maverick Wells Inc**.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

- `/` — Home
- `/about` — About Us
